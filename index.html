Real-Time Embedded Control System with FreeRTOS
Embedded #embedded-c #freertos #dspic #uart #adc #pwm

Multitasking FreeRTOS application on a dsPIC33FJ128MC802. It reads a DS18B20 1-Wire temperature sensor and drives a servo-actuated hatch via PWM, in automatic mode (temperature-based) or manual mode (potentiometer read through the ADC). Tasks are synchronized with mutexes, semaphores and queues. A UART command menu queries and switches the control mode and reads the temperature, while an LCD shows temperature, mode, voltage and the last command.
